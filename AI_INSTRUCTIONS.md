# Інструкції для AI Асистента (AI Prompt / Rules)

Ти працюєш у репозиторії **AI Reports Hub** (`C:\folder\JOB\VS_Code_AL\ai-reports`).
Цей проєкт містить інтерактивні HTML-звіти та дашборди, які автоматично розгортаються на **Vercel та Netlify** при пуші в гілку `main`.

Коли користувач просить тебе **створити новий звіт або оновити існуючий**, неухильно дотримуйся наступних правил:

---

## ⚡ ГОЛОВНІ ОБОВ'ЯЗКОВІ ВИМОГИ ДО КОЖНОГО ЗВІТУ

Кожен згенерований звіт **ОБОВ'ЯЗКОВО** повинен містити в інтерфейсі (у шапці або панелі керування):

### 1. Перемикач мови: EN / UA (Двомовність)
* **Завжди** передбачати підтримку двох мов: української (`UA`) та англійської (`EN`).
* У шапці звіту має бути видимий перемикач (наприклад, кнопка-тогл `[ UA | EN ]`).
* Усі заголовки, KPI-картки, назви метрик, підписи графіків та назви колонок таблиці повинні динамічно перекладатись при кліку на мову (через словник `const i18n = { en: {...}, ua: {...} }` у JS або data-атрибути).
* За замовчуванням мова: `UA` (або вибір користувача).

### 2. Меню експорту даних: CSV, EXCEL, PDF, JSON, MD
* **Завжди** має бути кнопка/випадаюче меню **«Експорт / Export ▾»**, яке підтримує завантаження даних у 5 форматах:
  1. **CSV** — файл `.csv` із кодуванням UTF-8 (з BOM `\uFEFF`, щоб коректно відкривався в Excel).
  2. **EXCEL (.xlsx)** — експорт таблиці у форматі Excel (через SheetJS CDN: `<script src="https://cdn.jsdelivr.net/npm/xlsx/dist/xlsx.full.min.js"></script>` або HTML-table blob).
  3. **PDF** — експорт у PDF (через `window.print()` з оптимізованими `@media print` стилями або `html2pdf.js` CDN).
  4. **JSON** — чистий структурований `.json` файл із даними дашборду.
  5. **MD (Markdown)** — текстовий файл `.md` зі зведеною таблицею та висновками звіту.

---

## 3. Архітектура та розташування файлів
* Кожен новий звіт має знаходитися у **власній окремій папці** з назвою файлу строго `index.html`:
  `/[slug-назва-звіту]/index.html` (наприклад, `/q4_finance/index.html`, `/seo_audit/index.html`).
* Жодних локальних npm-залежностей, збірок або Node.js компіляцій. Усі звіти повинні бути **100% автономними статичними HTML-файлами**.

---

## 4. Технічний стек звіту
* **Стилі:** Tailwind CSS через CDN:
  `<script src="https://cdn.tailwindcss.com"></script>`
* **Шрифти:** Google Fonts (Inter або схожі).
* **Графіки:** Chart.js через CDN (`https://cdn.jsdelivr.net/npm/chart.js`) або ApexCharts CDN.
* **Експорт в Excel:** SheetJS CDN (`https://cdn.jsdelivr.net/npm/xlsx/dist/xlsx.full.min.js`).
* **Тема за замовчуванням:** Сучасний темний інтерфейс (`bg-slate-950 text-slate-100`, картки `bg-slate-900/80 border border-slate-800`).
* **Компоненти:** KPI-картки, адаптивні графіки, інтерактивні фільтри, пошук по таблиці, сортування за колонками.

---

## 5. Обов'язкове оновлення головної сторінки (`/index.html`)
Після створення нового звіту у папці `/[slug]/index.html`:
1. Відкрий головний файл `index.html` у корені проєкту.
2. Знайди блок списку звітів.
3. Додай нову картку для створеного звіту з посиланням на `./[slug]/`, описом і назвою.
